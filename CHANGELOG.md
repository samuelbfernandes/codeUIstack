# Changelog

## [0.5.1] - unreleased
- **Nine new mods.** Seven are adapted from [whyashthakker/awesome-claude-code-mods](https://github.com/whyashthakker/awesome-claude-code-mods) (MIT, © 2026 Yash Thakker and contributors), rewritten in moddeck's style with tests: **staged-review** (the staged diff in a pane), **color-lab** (colour formats, WCAG contrast, the nearest passing shade), **csv-table** (preview a csv/tsv), **test-ledger** (every test, lint and build run with its result; now knows R, Rust, Ruff, Quarto and JS tools, not only pytest/jest/vitest), **scope-watch** (a note when Claude edits outside a folder you set), **error-inbox** (the last 30 failed tool calls, secrets scrubbed, "ask Claude" button) and **decision-log** (`/decision` adds a row to `docs/DECISIONS.md`). Two are new: **format-on-edit** (Air, Ruff, or the project's Prettier/Biome on each edited file; off until switched on) and **ui-preview** (runs a plumber API, JS dev server, Shiny or Streamlit app, lists plumber routes, takes a headless-Chrome screenshot, drafts a review prompt; localhost only).
- moddeck 0.8.0: the side bar lists the nine mods, with a new **UI development** card (ui-preview, color-lab); format-on-edit, test-ledger and error-inbox are switches.
- Installer: a new **UI development** list, third-party and never on by default (not picked by `--standard` or `--all`): Chrome DevTools MCP (pinned 1.10.1, `--no-usage-statistics --no-performance-crux`), Posit's btw and mcptools MCP servers for R, Posit's Shiny, Quarto and r-lib skills (adds the posit-dev/skills marketplace), Plotly Cloud MCP, and Anthropic's frontend-design. `--plan` names each source; `uninstall` removes the MCP servers and marketplaces it added and leaves ones you already had. New docs/UI-DEV.md lists these plus the programs to install yourself (Air, Ruff, jarl, the Shiny for Python, Streamlit, Gradio and Panel skills, Playwright CLI).
- New mod **concise** (off until switched on): while on, each prompt carries rules that shape replies so you can act on them (the next action first, numbered steps, state restated, no tangents, specific time estimates). Adapted from [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd) (MIT, © 2026 Ayoub Ghriss). moddeck 0.9.0 lists it as a switch under Prompt helpers.
- moddeck 0.9.6: picking an advisor model while `DISABLE_TELEMETRY` (or `CLAUDE_CODE_DISABLE_ADVISOR_TOOL`) keeps it off asks first: it says what is in the way and offers **Ask Claude to fix it**, which puts the request to remove the variable (and the installer's telemetry-off choice) in the prompt box. The installer's telemetry option now says it keeps the advisor off.
- moddeck 0.9.5: the advisor dropdown and name put `/advisor <model>` (or `/advisor off`) in the prompt box, since a mod cannot run Claude Code's own commands or write its settings; once sent, the row follows the saved `advisorModel`.
- moddeck 0.9.4: a card's name folds and opens it too, not only its triangle. Model controls gains **advisor**, a dropdown (off, opus, fable) for Claude Code's experimental advisor tool (`/advisor`), drawn like blast-radius (green on, red off, the name flips it); it shows the saved `advisorModel` and says so when `DISABLE_TELEMETRY` or `CLAUDE_CODE_DISABLE_ADVISOR_TOOL` keeps the advisor off.
- cache-tax 0.6.2 also works out the cache's lifetime the way Claude Code does (`cacheTtlMinutes` 0, the new default): `FORCE_PROMPT_CACHING_5M`, `CLAUDE_CODE_PROMPT_CACHE_TTL`, the `promptCacheTtl` setting, `ENABLE_PROMPT_CACHING_1H`, then 60 min on a subscription and 5 on usage credits or an API key; `/cache-tax` names the source. Adapted from prompt-cache-control (MIT).
- cache-tax 0.6.2: keep-warm uses the refreshes that cost nothing extra. Every request that reads the cache resets its lifetime, so each turn step, a side question or another plugin's fork now counts, and a ping goes out only after TTL minus 5 min with none (checked each minute instead of on a fixed beat). Expiry counts from the start of the last request that used the cache. Compared with claude-code-templates' observability/prompt-cache-control (MIT), which documents the same rule.
- moddeck 0.9.3: every card (each tool group, Skills, Prompts) has a ▾ after its title that folds it down to the title and its count; ▸ opens it again. Folded cards are kept between sessions.
- moddeck 0.9.2: the Skills and Prompts boxes end in a search field: matching names move to the top as you type (names that start with it first), the box title says how many match, and Enter puts the first in the prompt box. ＋ and − beside it still set the size.
- moddeck 0.9.1: the Side Question has an "Ask here" field beside its title (emptied after asking and by ✕ close), its title explains it on hover in the app, and ▸/▾ hides and shows the answers. When there is nothing to fork (a resumed or reloaded session) a side question is answered over the transcript's text instead of failing. Skills and prompts lists have ▲ ▼ arrows on their scroll bar, and the mouse wheel over a list works again. A tool group with more than 8 tools gets stars, shows 8 (or every star, at least 5) and scrolls with ▲ ▼; in every group starred tools come first, then switches that are on.
- moddeck 0.9.0: the Skills box lists every installed skill (the toolkit's own first, then the rest A to Z, read once per session from the engine's free local estimate). Skills and saved prompts get a ☆ star: starred items move to the top and the box grows to fit them all; each list shows at least 5 lines, "＋ more" and "− fewer" set the size when nothing is starred, and stars and sizes are kept between sessions. An answered side question has a "✕ close" button.
- New skill **no-ai-text**: edits AI tells out of a draft (or audits it without rewriting) and keeps the writer's voice. Merged from [petergyang/no-ai-slop](https://github.com/petergyang/no-ai-slop) and [blader/humanizer](https://github.com/blader/humanizer) (both MIT).
- savvy-progress 0.5.2: a version bump only, so installs pick up the 5.5 prices added in 0.5.0 (the version was not raised then, so an update kept the old copy).
- The capability audit now tracks Rscript, R and the formatters as programs; auto-test (Rscript) and repro-log (`R --version`) were already starting them and are now listed.
- moddeck 0.7.2: light colours for the desktop app (light fill, dark text, pale green, red and gray pills, since the app draws button text dark on a light theme). A mod cannot see the app's light or dark choice, so ☀ and ☾ at the top of the side bar, or `/moddeck theme light|dark` (setting `appTheme`, default dark), picks it and keeps it; the side bar no longer guesses from the theme in `/config`.

## [0.5.0] - 2026-10-13
- moddeck 0.7.1, the desktop app only (the terminal tree is unchanged): the switch names no longer read "suggest switch, off" (the app draws a button's label instead of its text, so buttons there carry none); a switch is a green or red pill and a command a gray one, the whole pill the button; every box may shrink below its text and clips it with "…", so boxes keep all four edges and nothing overlaps when the pane is dragged narrower; the duplicate title row and expand button are gone (the app's frame has both). On both surfaces a side bar click no longer adds a `moddeck:` note to the transcript: the engine already prints the reply under the command, and the note's newlines showed as stray glyphs in the terminal. Also on both surfaces: the cards stand in one column again, one under the other (the side-by-side cards of 0.7.0 are gone). In the app the pills are the "Deep solid" colours (white on deep green, red or gray, the same in every theme) and every box is filled, its text, descriptions and clickable words coloured for a dark theme, or a light one when `/config` names a light theme; skill and prompt names start with "/". The Session row reads `Mode: ` on both surfaces.
- auto-test 0.1.1, branch-janitor 0.4.2, budget-guard 0.4.1, cache-tax 0.6.1: transcript notes are written one line per `$.ui.log` call; a newline inside one call showed as a stray glyph in the terminal. Each line stays as it was so it can be copied: auto-test's failing output tail, branch-janitor's `git branch <name> <sha>` restore commands, and the prompt budget-guard and cache-tax hold back (indentation kept, a tab as two spaces). Blank lines are left out. Tested in the simulated engine only.
- moddeck 0.7.0: a more compact side bar. Each mod is one line: its name first (a switch is the name itself, a pill green when on and red when off; click it to flip, no more `on ●` / `● off` pill), then its controls, then its description, always last. review-cost is a plain switch (it has only on and off); blast-radius keeps its level dropdown right after its name, and its name switches it off and back to the level it had. Action labels are short (`[status]`, `[explain]`, `[recipe]`, `[run]`, `[$ warm]`, `[cool]`) so they fit on the line. On a wide pane the cards with short names share a line, each still its own box (the expand button now opens the pane 96 columns wide); text that does not fit is cut with "…" instead of wrapping. The **Side Question** panel moved up, right under the Session box. Skills and Prompts are boxed cards like the mods, with a description per line and a scroll bar (click its track, or the mouse wheel over the list) instead of ▲ / ▼ buttons. The "Tools" heading is gone. Tested in the simulated engine only.
- README: the mod count (twenty-one), the moddeck line, and the three newer skills (align, burst, assess-plugin) are current.
- moddeck: the skin dropdown is gone (tool-skins stays installed and keeps `/skin`). The "Plugins" heading is now "Tools"; every box title is bold; Skills and Prompts are plain lists with no box and no lines, a blank line apart.
- Prices brought up to the 2026-10-12 pricing page: cache-tax and savvy-progress know Fable 5.1 ($10/$50), Opus 5.5 ($4/$20), Sonnet 5.5 ($2/$10), Haiku 5.5 ($0.10/$0.50, the up-to-100K-token price) and the cheaper cache reads (0.05x on Opus 5.5 and Sonnet 5.5, 0.025x on Fable 5.1). suggest-model's default cost ratio is now `haiku=1,sonnet=20,opus=40` (was 1/3/5), so a cheaper-model suggestion shows the real gap.
- **aside is gone.** Its job moved into moddeck: a **Side Question** button (it expands the chat panel) at the bottom of the side bar (type in its field, or `/btw <question>`; answered over the cached context, never added to the chat, a little credit).
- moddeck: Update now passes `--scope user -y`, so the installer re-applies your recorded choices without asking questions (it hung waiting for answers). A per-project install is not updated this way: run `moddeck update --scope project` there.
- moddeck 0.6.0: the chat panel is one **Side Question** button that expands it; three Session rows: `mode` (permission mode, only when not the ordinary one), `backup` (time since the last commit or checkpoint and files unsaved) and an effort-fit `⚠` beside the effort in the model row (from suggest-model). Rows you hid or reordered with `/moddeck rows` before this version do not include the two new rows: `/moddeck rows show mode`, `show backup`.
- moddeck 0.6.0: an update check every time it is turned on (session start, or the side bar opened again; `git ls-remote --tags`, at most every 6 hours, setting `updateCheck`). A newer release asks Update now / Later / Skip this version; Update now runs the installer's own one-liner through pipx (else uvx) and says to restart. `/moddeck update` checks at once. Needs `git`; nothing is installed without your yes.
- suggest-model 0.4.0: effort-watch (setting `effortWatch`), a status-line note when the effort level does not fit the task. Part of suggest, not a separate mod.
- Three new skills from the guide: **align** (interview before a big build, then a spec), **burst** (three independent versions, graded), **assess-plugin** (what a plugin installs, costs and risks, before you install it).
- New docs/IDEAS.md: mods and skills suggested by the "23 Claude Mistakes" guide.
- cache-tax: choosing "Compact first" in the cold-cache question now compacts and re-sends your original message by itself (the engine refuses a compaction inside the prompt hook, so it runs on the next tick); if it cannot run, `/compact` goes in the prompt box as before. moddeck: `aside` is again its own row.
- moddeck 0.5.0: the side bar is one column of grouped cards (Prompt helpers, Guards, Automation, Model controls, Workspace utilities) with an icon, description, switch pill or dropdown and wrapping action buttons per row, a top bar with an expand button. Behaviour and commands are unchanged. suggest-model: a subagent start or model switch refused with "no verdict, issue the action again" is retried once.
- moddeck 0.2.6: blast-radius and review-cost are dropdowns (green on, red off); the whole row is clickable; the divider follows the width; a skin pick shows at once. blast-radius 0.3.3 gets `/blast-radius off|low|medium|high`, review-cost 0.3.1 gets `/review-cost on|off`. suggest-model 0.3.7 now says why a subagent could not start.
- New mods: **data-guard** (asks before committing large files, data files, personal-looking columns or notebooks with outputs; can strip outputs), **big-file-guard** (reads only the first lines of big data files and logs), **repro-log** (`/repro` writes a re-runnable recipe of the session), **auto-test** (runs your tests after a turn that changed code; off until switched on), **prompt-library** (`/prompts`: saved prompts, listed in the side bar), **checkpoint** (`/checkpoint`: safety snapshots of the working tree, restore asks what would be lost), **long-run-ping** (a ping when a long turn or command finishes). All appear in moddeck; moddeck 0.3.0 also lists saved prompts and scrolls the skills and prompts lists.
- moddeck 0.4.0: a live **Session** box at the top of the side bar (model, provider and effort, context bar, plan-usage bars with reset times, cost, cache expiry, git branch and file counts, tokens, recent tools, skills, MCP servers, compactions, config counts). Rows can be hidden or reordered and the layout made compact with `/moddeck rows list|hide <id>|show <id>|compact|expanded`. Usage windows that are on pace to run out are marked ▲.
- budget-guard 0.4.0: usage pace (▲, amber or red) and a cost ledger across sessions (`Today $x`, `Week $y`; `/budget-guard ledger`). cache-tax 0.6.0: the cache expiry as a clock time and the cache hit rate.
- Renamed the project to Moddeck (command `moddeck`, side bar `/moddeck`); installs made as `codeuistack` or `armory` move over on the next install.
- New mod **moddeck**: a side bar with every mod and skill. Switches for suggest, reflect and secret-guard (green on, red off) flip at once, a dropdown picks the skin, other items fill the prompt box. aside's and suggest-model's on/off moved there from the band above the prompt (suggest-model no longer draws anything above it); reflect now mirrors its switch so the side bar can show it. The skills list scrolls on its own (▲ up / ▼ down, one row at a time, `skillRows` setting, default four) once there are more skills than fit.
- blast-radius: the risk level carries a coloured dot (🔴 high and unknown, 🟠 medium, 🟢 low).
- blast-radius: new `askFrom` setting (low, medium, high). The default, medium, runs low-risk commands without a dialog; unknown and unchecked commands always ask.
- cache-tax: the cold-cache dialog suggests the cheapest way forward (compact, start fresh, or send) and can put /compact or /clear in the prompt box.
- Renamed the mod model-fit to suggest-model (plugin id, command, plain words `suggest-model` / `suggest model`, settings key). Reinstall with `moddeck install`.
- Commands now always start with `/`: the typed plain words are gone from every mod (a bare word is an ordinary prompt). The moddeck rows run or fill the same `/commands`; a tool with a single task is just its row, and options show under their row (suggest-model only while its switch is on).
- budget-guard: the limit is in plan-window terms (used/total), `/budget-guard 80` (setting `limitPct`), and in dollars for API-key use, `/budget-guard $10` (setting `limitUsd`). The dialog fires on either.
- savvy-progress: a finished helper's bar is full, a failed or stopped one's stays where it stopped. A running helper that reports nothing for `stallMinutes` (default 5) shows as stalled with its Stop button and one toast.
- aside: a green/red on/off chip above the prompt (click it), plus `aside on` / `aside off` and `/aside on|off`; the choice is remembered.
- `install --standard` and `install --all`: one-line, no-questions installs (the recommended set, or every mod, rule, skill and git guard). suggest-model: the green/red chip is itself the button; the separate Turn on/off button is gone.

## [0.3.2] - unreleased
